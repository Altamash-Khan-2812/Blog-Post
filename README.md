# Simple Blog App (Node.js + MongoDB)

This is a learning project built using **Node.js**, **Express**, **EJS**, and **MongoDB**. It demonstrates how to **connect a Node.js app to a No SQL database**, perform **CRUD operations**, and render **dynamic pages** using EJS templates.

## Features

- View all blog posts
- View details of a single post
- Create a new post
- Edit an existing post
- Delete a post
- Display author information by fetching the author details from database

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Templating Engine:** EJS
- **Static Files:** Public folder for CSS and assets
