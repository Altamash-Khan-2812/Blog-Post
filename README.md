# Simple Blog App (Node.js + MySQL)

This is a learning project built using **Node.js**, **Express**, **EJS**, and **MySQL**. It demonstrates how to **connect a Node.js app to a SQL database**, perform **CRUD operations**, and render **dynamic pages** using EJS templates.

---

## Features

- View all blog posts
- View details of a single post
- Create a new post
- Edit an existing post
- Delete a post
- Display author information linked through SQL relationships

---

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MySQL (via `mysql2` library)
- **Templating Engine:** EJS
- **Static Files:** Public folder for CSS and assets
